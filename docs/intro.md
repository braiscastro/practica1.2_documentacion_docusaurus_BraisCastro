# Documentación de GestorLocal

## Introducción

GestorLocal es una aplicación web ficticia diseñada para facilitar la gestión de pequeños negocios. Centraliza la información de clientes, productos y pedidos.

## Objetivos

- Registrar y consultar clientes.
- Gestionar un catálogo de productos.
- Crear y consultar pedidos.
- Facilitar el seguimiento de las operaciones del negocio.

## Tecnologías

- TypeScript.
- Docusaurus.
- Markdown.
- Git y GitHub.

## Organización

La documentación se divide en análisis de requisitos, diseño, implementación, pruebas y despliegue.
