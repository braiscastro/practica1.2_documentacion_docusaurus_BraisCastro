# Estructura del proyecto

## Organización

- `docs/`: documentación técnica en Markdown.
- `src/`: páginas y componentes personalizados.
- `static/`: imágenes y recursos estáticos.
- `docusaurus.config.ts`: configuración general.
- `sidebars.ts`: configuración del menú lateral.
- `package.json`: dependencias y comandos.
- `package-lock.json`: versiones de dependencias instaladas.

## Instalación

Se ejecuta `npm install`.

## Desarrollo

Se inicia el servidor con `npm run start`.

## Generación

Se ejecuta `npm run build`.

El resultado se almacena en la carpeta `build/`, preparada para su publicación.
