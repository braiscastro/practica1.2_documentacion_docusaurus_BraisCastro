# Análisis de requisitos

## Descripción

GestorLocal permite a los empleados de un pequeño negocio administrar clientes, productos y pedidos.

## Requisitos funcionales

- RF01: registrar nuevos clientes.
- RF02: consultar clientes registrados.
- RF03: crear productos con nombre, precio y stock.
- RF04: crear pedidos asociados a un cliente.
- RF05: calcular el importe total de cada pedido.

## Requisitos no funcionales

- RNF01: la interfaz será intuitiva.
- RNF02: los datos se validarán antes de guardarse.
- RNF03: funcionará en navegadores modernos.
- RNF04: las funciones de gestión estarán protegidas mediante autenticación.

## Usuarios

El usuario principal será el empleado o responsable del negocio.
